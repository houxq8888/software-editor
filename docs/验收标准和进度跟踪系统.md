### 2. 进度计算公式

**总体进度 = Σ(任务权重 × 任务完成度)**

**任务完成度评估标准：**
- 0%：未开始
- 25%：代码框架搭建完成
- 50%：核心功能实现
- 75%：功能测试通过
- 100%：验收标准全部满足

## 进度可视化

### 1. 进度仪表板
```python
# progress_dashboard.py
import matplotlib.pyplot as plt

def create_progress_chart(progress_data):
    """创建进度可视化图表"""
    weeks = ['第1周', '第2周', '第3周', '第4周', '第5-8周']
    planned = [25, 50, 75, 100, 100]
    actual = progress_data['weekly_progress']
    
    plt.figure(figsize=(10, 6))
    plt.plot(weeks, planned, 'b--', label='计划进度')
    plt.plot(weeks, actual, 'r-', label='实际进度')
    plt.fill_between(weeks, planned, actual, alpha=0.3)
    plt.title('项目开发进度跟踪')
    plt.xlabel('开发周数')
    plt.ylabel('完成百分比')
    plt.legend()
    plt.grid(True)
    plt.show()
```
