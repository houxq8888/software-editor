# Software Editor - 软件编辑器

一个基于Qt框架开发的可视化产品编辑工具，专为不会写代码的产品工程师设计。通过模块化架构，提供产品配置编辑、UI布局设计和智能打包等完整功能。

## 项目架构

项目采用模块化设计，分为三大核心模块：

### 1. 产品配置编辑模块 (src/product/)
- 产品信息管理（名称、版本、分类等）
- 功能特性编辑
- 产品状态管理
- 配置模板支持

### 2. UI布局编辑器模块 (src/uilayout/)
- 可视化控件拖拽
- 属性编辑器
- 实时预览功能
- 事件-动作编辑器
- UI接口管理

### 3. 智能打包模块 (src/package/)
- NSIS安装包生成
- 依赖库自动复制
- 多平台支持
- 打包配置管理

## 主要功能

- **可视化产品配置**：无需编码，通过界面完成产品信息编辑
- **拖拽式UI设计**：直观的界面布局编辑
- **智能打包**：一键生成可执行文件和安装包
- **实时预览**：即时查看设计效果
- **跨平台支持**：基于Qt框架，支持Windows、Linux、macOS

## 技术栈

- **框架**：Qt 6.x
- **语言**：C++
- **构建工具**：CMake
- **打包工具**：NSIS
- **UI格式**：Qt Designer .ui文件

## 快速开始

### 编译运行
```bash
# 使用build.bat编译
.\build.bat

# 运行程序
.\build\software-editor.exe
```

### 测试脚本
测试脚本位于 `test/ui_automation/` 目录下。
