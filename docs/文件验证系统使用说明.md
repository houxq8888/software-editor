# 文件验证系统使用说明

## 概述

本文件验证系统为软件提供了一种规范化的文件夹结构，能够在软件启动时自动识别并验证所有必需的文件。系统按照文件的类型和角色进行分类存放，确保文件管理和版本控制更清晰、简洁。

## 规范化文件夹结构

```
/product_configurations
    /product_12345
        product_config.json        # 产品配置文件
        /ui_layouts                # UI布局文件集合
            43214.ui              # UI布局文件1
            1208.ui               # UI布局文件2
            1209.ui               # UI布局文件3
        /state_machines            # 状态机文件集合
            state_machine_1.json  # 状态机文件1
            state_machine_2.json  # 状态机文件2
        /resources                 # 其它资源，如图标、截图等
            icon.png
            screenshot.png
```

## 产品配置文件格式

产品配置文件 `product_config.json` 包含以下主要部分：

### 产品信息
```json
"productInfo": {
    "uniqueId": "b3836d3c-f2c5-4dcb-9fc7-52f5b0617cde",
    "name": "Test_20251121_113422",
    "version": "1.0.0",
    "category": "工具软件",
    "description": "这是一个测试产品，创建于20251121_113422",
    "developer": "测试开发者",
    "website": "https://example.com"
}
```

### 文件结构定义
```json
"fileStructure": {
    "basePath": "product_configurations/product_12345",
    "uiLayoutsPath": "ui_layouts",
    "stateMachinesPath": "state_machines",
    "resourcesPath": "resources"
}
```

### 文件引用
```json
"uiFiles": [
    {
        "name": "43214",
        "fileName": "43214.ui",
        "description": "UI布局文件: 43214",
        "isMain": true,
        "order": 0,
        "type": "ui_layout"
    }
],
"stateMachines": [
    {
        "name": "state_machine_1",
        "fileName": "state_machine_1.json",
        "description": "主状态机文件"
    }
],
"resources": {
    "icon": "icon.png",
    "screenshot": "screenshot.png"
}
```

## 软件启动验证流程

当用户启动软件时，软件将按以下顺序执行检查：

### 1. 加载产品配置文件
- 加载并解析 `product_config.json` 文件
- 确认产品的基本信息

### 2. 验证 UI 布局文件
- 检查 `uiFiles` 数组中列出的文件是否都存在于 `/ui_layouts` 文件夹中
- 验证主UI文件是否存在

### 3. 验证状态机文件
- 检查 `stateMachines` 数组中列出的文件是否都存在于 `/state_machines` 文件夹中

### 4. 验证资源文件
- 检查 `resources` 中引用的文件是否都存在于 `/resources` 文件夹中

### 5. 缺失文件提示
- 如果任何文件缺失，软件将提示用户
- 列出缺失的文件名称和路径
- 提供详细的验证报告

## 集成到主应用程序

### 方法一：使用现有的产品加载器

```python
from scripts.product_loader import ProductLoader

# 创建产品加载器
loader = ProductLoader("product_configurations")

# 启动应用程序
success = loader.start_application()

if success:
    # 应用程序启动成功，继续正常流程
    print("应用程序已成功启动！")
else:
    # 处理启动失败的情况
    print("应用程序启动失败，请检查缺失的文件。")
```

### 方法二：自定义验证流程

```python
from scripts.file_validator import FileValidator

# 创建文件验证器
validator = FileValidator("product_configurations/product_12345")

# 执行验证
validation_result = validator.validate_product_config(
    "product_configurations/product_12345/product_config.json"
)

# 检查验证结果
if validation_result["overallStatus"] == "valid":
    print("所有文件验证通过")
elif validation_result["overallStatus"] == "incomplete":
    print(f"文件验证不完整，缺失 {len(validation_result['missingFiles'])} 个文件")
    for missing_file in validation_result["missingFiles"]:
        print(f"  - {missing_file}")
else:
    print("文件验证失败")

# 生成验证报告
report = validator.generate_validation_report(validation_result)
print(report)
```

## 优势

1. **规范化管理**: 统一的文件夹结构，便于文件管理
2. **自动验证**: 软件启动时自动检查所有必需文件
3. **详细报告**: 提供清晰的验证报告和缺失文件列表
4. **易于扩展**: 支持添加新的文件类型和验证规则
5. **错误处理**: 友好的错误提示和恢复机制

## 注意事项

1. 确保产品配置文件的路径正确
2. 所有引用的文件必须存在于对应的文件夹中
3. 文件名称必须与配置文件中的定义完全匹配
4. 建议在软件发布前进行完整的文件验证测试

## 故障排除

### 常见问题

1. **配置文件无法加载**: 检查JSON格式是否正确
2. **文件路径错误**: 确认基础路径和相对路径设置正确
3. **文件权限问题**: 确保应用程序有读取文件的权限
4. **编码问题**: 确保所有文件使用UTF-8编码

### 调试方法

1. 启用详细日志记录
2. 检查验证报告中的具体错误信息
3. 手动验证文件路径和权限
4. 使用测试脚本进行隔离测试
