# Software Editor - 代码架构文档

## 项目概述

Software Editor 是一个集产品配置编辑、UI布局设计和智能打包于一体的软件开发工具。项目采用模块化架构设计，将功能划分为三个核心模块，每个模块职责清晰，便于维护和扩展。

## 整体架构

### 模块化架构设计

项目采用三层模块化架构：

```
software-editor/
├── src/
│   ├── product/          # 产品配置编辑模块
│   ├── uilayout/         # UI布局编辑器模块  
│   ├── package/          # 智能打包模块
│   └── main.cpp          # 应用程序入口
├── build/                # 构建输出目录
├── docs/                 # 项目文档
└── test/                 # 测试脚本
```

### 模块职责划分

#### 1. 产品配置编辑模块 (src/product/)

**核心职责**：管理产品的基本信息、功能特性和配置数据

**主要组件**：
- **MainWindow** (`mainwindow.h/cpp`)：应用程序主窗口，集成所有功能模块
- **Product** (`product.h/cpp`)：产品信息数据模型，包含产品基本属性
- **ProductConfigManager** (`productconfigmanager.h/cpp`)：产品配置管理，处理配置的保存和加载
- **ProductState** (`productstate.h/cpp`)：产品状态管理，跟踪产品修改状态
- **Template.json** (`template.json`)：产品配置模板，提供默认配置结构

**关键特性**：
- 支持产品基本信息编辑（名称、版本、分类等）
- 功能特性管理
- 截图和图标配置
- 配置模板支持

#### 2. UI布局编辑器模块 (src/uilayout/)

**核心职责**：提供可视化的UI布局设计和交互逻辑编辑功能

**主要组件**：
- **UILayoutWindow** (`uilayoutwindow.h/cpp`)：UI布局编辑主界面
- **PreviewWindow** (`previewwindow.h/cpp`)：实时预览窗口
- **EditAreaWidget** (`editareawidget.h/cpp`)：编辑区域组件
- **CustomTreeWidget** (`customtreewidget.h/cpp`)：自定义树形控件
- **EventActionEditor** (`eventactioneditor.h/cpp`)：事件-动作编辑器
- **UIInterfaceManager** (`uiinterfacemanager.h/cpp`)：UI接口管理
- **EventActionModel** (`eventactionmodel.h/cpp`)：事件-动作数据模型

**关键特性**：
- 控件拖拽布局
- 属性实时编辑
- 事件-动作可视化配置
- 实时预览功能
- UI组件层次管理

#### 3. 智能打包模块 (src/package/)

**核心职责**：根据产品配置和UI布局生成可安装的软件包

**主要组件**：
- **PackageManager** (`packagemanager.h/cpp`)：打包管理器
- **PackageService** (`packageservice.h/cpp`)：打包服务实现
- **PackageConfig** (`packageconfig.h/cpp`)：打包配置管理
- **IPackageService** (`ipackageservice.h/cpp`)：打包服务接口

**关键特性**：
- NSIS安装包自动生成
- Qt依赖库自动复制
- 多平台安装包支持
- 打包进度可视化

## 模块间协作机制

### 数据流设计

```
产品配置模块 → UI布局模块 → 智能打包模块
     ↓              ↓             ↓
配置数据 → UI布局数据 → 安装包生成
```

### 通信机制

1. **事件驱动**：各模块通过Qt信号槽机制进行通信
2. **接口隔离**：模块间通过定义良好的接口进行交互
3. **数据共享**：通过ProductConfigManager统一管理配置数据

### 依赖关系

- **MainWindow** 依赖所有三个模块的UI组件
- **智能打包模块** 依赖产品配置和UI布局数据
- **UI布局模块** 依赖产品配置信息
- 各模块内部组件高度内聚，外部依赖最小化

## 技术架构

### 开发框架
- **Qt 5.15+**：跨平台GUI应用程序框架
- **C++17**：现代C++标准，支持RAII、智能指针等特性
- **CMake**：跨平台构建系统

### 设计模式
- **MVC模式**：数据模型、视图和控制器的分离
- **观察者模式**：通过信号槽实现组件间通信
- **工厂模式**：UI组件和打包服务的创建
- **策略模式**：支持不同的打包策略

### 数据存储
- **JSON格式**：产品配置和UI布局数据存储
- **模板驱动**：通过template.json提供默认配置
- **版本管理**：配置文件的版本兼容性处理

## 构建系统

### CMake配置
项目使用CMake进行跨平台构建，主要配置包括：

```cmake
# 模块化头文件路径配置
include_directories(
    src
    src/product
    src/uilayout  
    src/package
)

# 源文件按模块组织
add_executable(software-editor
    src/main.cpp
    # 产品配置模块源文件
    src/product/mainwindow.cpp
    src/product/product.cpp
    src/product/productconfigmanager.cpp
    src/product/productstate.cpp
    # UI布局模块源文件
    src/uilayout/uilayoutwindow.cpp
    src/uilayout/previewwindow.cpp
    # ... 其他源文件
)
```

## 总结

Software Editor采用清晰的模块化架构设计，将复杂的功能划分为三个职责明确的模块。这种架构设计具有以下优势：

1. **高内聚低耦合**：每个模块功能集中，模块间依赖清晰
2. **易于维护**：模块边界明确，便于独立开发和测试
3. **可扩展性强**：预留插件接口，支持功能扩展
4. **代码复用**：模块化设计便于代码复用和重构

这种架构为项目的长期发展和功能扩展奠定了坚实的基础。
