# 状态机编辑器使用示例

## 概述

状态机编辑器是软件编辑器中的一个重要组件，用于设计和可视化状态机模型。每个状态可以关联不同的UI界面，实现状态驱动的界面切换。

## 核心组件

### 1. StateMachineEditor（状态机编辑器主窗口）
- 包含状态图视图、属性面板、工具栏
- 管理状态机的创建、加载、保存
- 处理状态和转换的选择事件

### 2. StateMachineScene（状态机场景）
- 图形化显示状态机模型
- 包含状态节点（StateNode）和转换边（TransitionEdge）
- 处理鼠标交互和选择事件

### 3. StateNode（状态节点）
- 表示状态机中的一个状态
- 显示状态名称、描述、关联UI界面
- 支持点击选择、双击编辑、右键菜单

## 使用步骤示例

### 步骤1：启动程序并打开状态机编辑器

```bash
# 编译程序
.\build.bat

# 启动程序
.\build\software-editor.exe
```

### 步骤2：创建新状态机

1. 在程序主界面中找到状态机编辑器
2. 点击"新建状态机"按钮
3. 系统会创建一个空的状态机，包含默认的初始状态

### 步骤3：添加状态节点

1. 在状态图视图中**右键点击空白区域**
2. 选择"添加状态"
3. 输入状态名称和描述
4. 重复此过程添加多个状态

### 步骤4：设置状态属性

1. **点击选择状态节点**（左键单击）
2. 观察属性面板的变化 - 会显示选中状态的详细信息
3. 在属性面板中设置：
   - 状态名称
   - 状态描述
   - 是否为初始状态
   - 是否为最终状态
   - **关联的UI界面**（重点）

### 步骤5：关联UI界面

1. 确保已选中一个状态节点
2. 在属性面板中找到"UI界面"下拉框
3. 选择要关联的UI界面文件
4. 状态节点上会显示绿色"UI"标识
5. 鼠标悬停会显示关联的UI界面信息

### 步骤6：添加状态转换

1. 在状态图视图中右键点击状态节点
2. 选择"添加转换"
3. 选择目标状态
4. 在属性面板中设置转换事件和条件

## 代码逻辑详解

### 状态选择机制

```cpp
// StateNode中的鼠标点击事件
void StateNode::mousePressEvent(QGraphicsSceneMouseEvent *event)
{
    if (event->button() == Qt::LeftButton) {
        StateMachineScene *scene = qobject_cast<StateMachineScene*>(this->scene());
        if (scene) {
            emit scene->stateSelected(m_state); // 发出状态选中信号
        }
    }
}

// StateMachineEditor接收状态选择信号
void StateMachineEditor::onStateSelected(const StateMachineState &state)
{
    m_currentState = state;           // 保存当前选中状态
    updatePropertiesPanel();          // 更新属性面板显示
}
```

### UI界面关联逻辑

```cpp
// UI界面选择改变时的处理
void StateMachineEditor::onUiInterfaceChanged(int index)
{
    if (index < 0) return;
    
    QString uiInterfaceId = m_uiInterfaceCombo->currentData().toString();
    
    // 检查是否有选中的状态
    if (m_currentState.stateId.isEmpty()) {
        qDebug() << "当前没有选中任何状态，UI界面选择不会生效";
        return;
    }
    
    // 更新当前状态的UI界面ID
    m_currentState.uiInterfaceId = uiInterfaceId;
    
    // 更新状态机并刷新显示
    if (m_stateMachineManager && m_stateMachineManager->currentStateMachine()) {
        m_stateMachineManager->currentStateMachine()->updateState(m_currentState);
        m_scene->refreshScene();
        
        qDebug() << "状态" << m_currentState.name << "的UI界面已更新为:" 
                 << m_uiInterfaceCombo->currentText() << "(" << uiInterfaceId << ")";
    }
}
```

### 状态节点UI标识显示

```cpp
// StateNode中更新UI界面标识
void StateNode::updateUiInterfaceIndicator()
{
    if (!m_uiInterfaceIndicator) {
        m_uiInterfaceIndicator = new QGraphicsTextItem(this);
        m_uiInterfaceIndicator->setFont(QFont("Arial", 8));
        m_uiInterfaceIndicator->setDefaultTextColor(Qt::green);
        m_uiInterfaceIndicator->setPos(5, 5);
    }
    
    if (!m_state.uiInterfaceId.isEmpty()) {
        m_uiInterfaceIndicator->setPlainText("UI");
        m_uiInterfaceIndicator->setToolTip("关联UI界面: " + m_state.uiInterfaceId);
    } else {
        m_uiInterfaceIndicator->setPlainText("");
    }
}
```

## 常见问题解决

### 问题1："当前没有选中任何状态，UI界面选择不会生效"

**原因**：没有选中任何状态节点就尝试设置UI界面
**解决**：先点击选择一个状态节点，然后再设置UI界面

### 问题2：状态节点上没有显示UI标识

**原因**：状态没有关联UI界面，或者UI界面标识未正确创建
**解决**：确保已为状态设置了UI界面，并检查状态节点的updateUiInterfaceIndicator方法

### 问题3：属性面板不显示状态信息

**原因**：状态选择信号未正确连接
**解决**：检查StateMachineEditor中的信号连接代码

## 扩展功能

### 运行时预览
状态机编辑器支持运行时预览功能，可以模拟状态转换和UI界面切换。

### 状态机验证
提供状态机验证功能，检查状态机的完整性和正确性。

## 总结

状态机编辑器通过图形化界面简化了状态机的设计过程，特别是UI界面与状态的关联功能，使得状态驱动的界面开发更加直观和高效。掌握状态选择、UI关联等基本操作后，可以快速构建复杂的交互式应用程序。
