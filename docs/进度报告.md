## 最新技术进展

### UI交互逻辑编辑器功能 (2026-01-19)

**功能概述**：
实现了完整的UI交互逻辑编辑器功能，分为三个子功能模块：
1. **向导编辑**：编辑多个UI界面之间的跳转关系，创建UI向导流程
2. **逻辑时序编辑**：编辑业务逻辑运行流程，定义内部执行流程逻辑
3. **UI与执行模块绑定**：可视化绑定UI控件与执行模块，实现UI与后端逻辑的连接

**核心功能**：

1. **向导编辑功能** (src/uilayout/statemachineeditor_v2.cpp)
   - 支持UI流模式和逻辑时序模式
   - 可视化编辑UI界面交互流程
   - UI文件列表管理
   - 主界面设置功能
   - 控件事件定义系统

2. **控件事件定义系统**
   - 定义UI控件的事件类型（如clicked）
   - 设置事件名称和目标UI页面
   - 支持无跳转事件（保持当前页面）
   - 事件数据存储和解析

3. **向导页面顺序构建**
   - 根据控件事件定义构建UI跳转关系图
   - 从主界面开始，按照跳转关系组织页面顺序
   - 自动处理孤立UI（无跳转事件的UI）
   - 防止循环引用

4. **向导预览功能**
   - 动态加载UI文件到预览窗口
   - 自动绑定控件事件到目标UI页面
   - 基于控件事件实现页面跳转（非机械式导航）
   - 移除固定的"上一步"、"下一步"按钮
   - 支持clicked等事件类型

5. **逻辑时序编辑功能**（待开发）
   - 可视化编辑业务逻辑的执行顺序
   - 支持条件分支和循环逻辑
   - 定义数据流转和处理步骤
   - 配置异步任务和并发执行

6. **UI与执行模块绑定功能**（待开发）
   - 可视化绑定UI控件与执行模块
   - 支持多种绑定类型（数据绑定、事件绑定、属性绑定）
   - 实时预览绑定效果
   - 管理绑定关系和依赖

**技术实现**：

1. **数据结构** (src/uilayout/statemachineeditor_v2.h)
   ```cpp
   struct UITransition {
       QString sourceUIPath;    // 源UI文件路径
       QString eventName;        // 事件名称
       QString controlName;      // 控件名称
       QString eventType;        // 事件类型
       QString targetUIPath;     // 目标UI文件路径（空表示无跳转）
   };
   ```

2. **核心方法**
   - `parseUITransitions()`: 解析所有UI跳转关系
   - `buildWizardPageOrder()`: 根据跳转关系构建向导页面顺序
   - `bindControlEvents()`: 绑定控件事件到目标UI页面
   - `handleControlEvent()`: 处理控件事件触发的页面跳转

3. **向导预览窗口** (WizardPreviewWidget)
   - 支持动态加载UI文件
   - 自动绑定控件事件
   - 基于事件驱动的页面导航
   - 实时预览向导运行效果
