# 软件操作说明书

## 1. 软件概述

该软件是一个可视化UI布局编辑器，允许用户通过拖拽控件来创建和编辑GUI界面。

## 2. 界面结构

软件主界面分为三个主要区域：
- **左侧控件库**：包含各种可用的Qt控件（如QLabel、QPushButton、QLineEdit等）
- **中间编辑区**：用于创建和编辑UI布局的主区域
- **右侧属性编辑器**：用于修改选中控件的属性

## 3. 基本操作

### 3.1 控件拖拽
1. 在左侧控件库中选择一个控件（如QLabel）
2. 按住鼠标左键将其拖拽到中间编辑区
3. 释放鼠标左键，控件将被添加到编辑区

### 3.2 控件编辑

#### 3.2.1 QLabel文本编辑
1. 在编辑区双击QLabel控件
2. 进入文本编辑模式，输入新的文本
3. 点击编辑区空白处或按下Enter键完成编辑

#### 3.2.2 QTabWidget标签编辑
1. 在编辑区双击QTabWidget的某个标签页标题
2. 进入标签编辑模式，输入新的标签名称
3. 点击编辑区空白处或按下Enter键完成编辑

### 3.3 属性修改
1. 在编辑区选中一个控件
2. 右侧属性编辑器将显示该控件的所有可编辑属性
3. 双击属性值列进行修改
4. 修改完成后，按下Enter键或点击其他位置保存更改

### 3.4 预览功能
1. 点击工具栏中的"预览"按钮
2. 在弹出的预览窗口中可以交互测试UI界面
3. 可以点击按钮、在输入框中输入文本等

## 4. 布局调整

### 4.1 控件大小调整
1. 选中编辑区中的控件
2. 控件周围将显示调整控制点
3. 拖拽控制点可以调整控件的大小

### 4.2 控件位置调整
1. 选中编辑区中的控件
2. 按住鼠标左键拖拽控件到新的位置
3. 释放鼠标左键完成位置调整

### 4.3 分隔条调整
1. 左侧控件库和中间编辑区之间有一个分隔条
2. 按住鼠标左键拖拽分隔条可以调整两个区域的大小

## 5. 高级功能

### 5.1 布局保存
1. 点击"文件"菜单中的"保存"选项
2. 选择保存路径和文件名
3. UI布局将以.ui文件格式保存

### 5.2 布局加载
1. 点击"文件"菜单中的"打开"选项
2. 选择要加载的.ui文件
3. 文件将在编辑区中打开

## 6. 快捷键

- Ctrl+S：保存布局
- Ctrl+O：打开布局
- Delete：删除选中的控件
- Ctrl+Z：撤销操作
- Ctrl+Y：重做操作

## 7. 注意事项

1. 确保在编辑完成后保存布局
2. 预览功能可以帮助验证UI的交互性
3. 某些属性修改可能需要重新预览才能生效
