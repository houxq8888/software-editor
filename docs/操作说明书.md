# 软件操作说明书

## 1. 软件概述

该软件是一个基于模块化架构的软件产品编辑器，包含三大核心功能模块：
- **产品配置编辑模块**：编辑软件产品的基本信息，保存为JSON格式
- **UI布局编辑器模块**：可视化编辑GUI界面布局，保存为UI格式
- **智能打包模块**：将产品配置和UI布局打包成可执行文件和安装包

## 2. 模块化架构说明

### 2.1 产品配置编辑模块 (src/product/)
负责产品信息的完整生命周期管理：
- **MainWindow**：主窗口界面，集成所有功能模块
- **Product**：产品信息数据模型
- **ProductConfigManager**：产品配置管理
- **ProductState**：产品状态管理
- **Template.json**：产品配置模板

### 2.2 UI布局编辑器模块 (src/uilayout/)
提供完整的UI设计功能：
- **UILayoutWindow**：UI布局编辑主界面
- **PreviewWindow**：实时预览窗口
- **EditAreaWidget**：编辑区域组件
- **CustomTreeWidget**：自定义树形控件
- **EventActionEditor**：事件-动作编辑器
- **UIInterfaceManager**：UI接口管理
- **StateMachineEditorV2**：UI流状态机编辑器（支持向导功能）
- **Wizard**：向导管理类
- **WizardPreviewWidget**：向导预览窗口

### 2.3 UI交互逻辑模块 (src/uilayout/statemachineeditor_v2.cpp)
提供UI界面交互流程编辑功能，分为三个子功能：
- **向导编辑**：编辑多个UI界面之间的跳转关系，创建UI向导流程
- **逻辑时序编辑**：编辑业务逻辑运行流程，定义内部执行流程逻辑
- **UI与执行模块绑定**：可视化绑定UI控件与执行模块，实现UI与后端逻辑的连接

### 2.4 智能打包模块 (src/package/)
实现自动化打包功能：
- **PackageManager**：打包管理器
- **PackageService**：打包服务实现
- **PackageConfig**：打包配置管理
- **IPackageService**：打包服务接口

## 2. 界面结构

软件主界面包含以下主要组件：
- **菜单栏**：文件、UI布局、帮助三个菜单
- **工具栏**：常用功能的快捷按钮
- **产品信息编辑窗口**：编辑软件产品的基本信息
- **状态栏**：显示当前状态信息

   - 产品描述
   - 产品图标路径
   - 产品截图路径

### 3.2 功能特性编辑

## 4. UI布局编辑

### 4.1 打开UI布局编辑器
1. 点击菜单栏中的"UI布局"→"打开UI布局编辑器"
2. 进入UI布局编辑界面

### 4.2 控件拖拽
1. 在左侧控件库中选择一个控件（如QLabel）
2. 按住鼠标左键将其拖拽到中间编辑区
3. 释放鼠标左键，控件将被添加到编辑区

### 4.3 控件编辑

#### 4.3.1 QLabel文本编辑
1. 在编辑区双击QLabel控件
2. 进入文本编辑模式，输入新的文本
3. 点击编辑区空白处或按下Enter键完成编辑

#### 4.3.2 QTabWidget标签编辑
1. 在编辑区双击QTabWidget的某个标签页标题
2. 进入标签编辑模式，输入新的标签名称
3. 点击编辑区空白处或按下Enter键完成编辑

### 4.4 属性修改
1. 在编辑区选中一个控件
2. 右侧属性编辑器将显示该控件的所有可编辑属性
3. 双击属性值列进行修改
4. 修改完成后，按下Enter键或点击其他位置保存更改

### 4.5 预览功能
1. 点击工具栏中的"预览"按钮
2. 在弹出的预览窗口中可以交互测试UI界面
3. 可以点击按钮、在输入框中输入文本等

### 4.6 UI布局绑定管理

#### 4.6.1 UI布局绑定流程
当UI布局窗口关闭时，系统会自动检测UI布局路径的变化，并根据用户的操作进行相应的处理：

1. **UI布局路径未变化**：
   - 如果当前UI布局路径与产品UI布局路径相同，说明没有新的UI布局文件加载
   - 系统不会进行任何绑定询问，保持原有状态

2. **UI布局路径变化但内容未修改**：
   - 如果用户只是打开了新的UI布局文件但没有做任何修改
   - 系统会自动将UI布局路径改回原来的产品路径
   - 不会弹出绑定询问对话框

3. **UI布局路径变化且内容已修改**：
   - 如果用户打开了新的UI布局文件并进行了修改
   - 系统会弹出绑定询问对话框，询问用户是否要为当前产品绑定这个UI布局
   - 用户可以选择"是"进行绑定，或选择"否"取消绑定

#### 4.6.2 用户操作选项

**选择"是"（绑定UI布局）**：
- 系统会将新的UI布局文件绑定到当前产品
- 产品的UI布局路径会被更新为新文件的路径
- 产品信息会被标记为已修改，需要保存

**选择"否"（取消绑定）**：
- 系统会将UI布局路径改回原来的产品路径
- 新加载的UI布局文件不会被绑定到产品
- 产品信息保持原有状态

#### 4.6.3 特殊情况处理

**用户选择"丢弃"操作**：
- 在UI布局窗口关闭时，如果用户选择"丢弃"修改
- 系统会重置UI布局的修改状态
- 在MainWindow中检测到路径变化但内容未修改时，会自动将路径改回产品路径

**用户选择"保存"操作**：
- 在UI布局窗口关闭时，如果用户选择"保存"修改
- 系统会更新UI布局路径到ProductConfigManager
- 在MainWindow中检测到路径变化且内容已修改时，会触发绑定询问

### 4.7 预览功能
1. 点击工具栏中的"预览"按钮
2. 在弹出的预览窗口中可以交互测试UI界面

### 5.1 控件大小调整
1. 选中编辑区中的控件
2. 控件周围将显示调整控制点
3. 拖拽控制点可以调整控件的大小

### 5.2 控件位置调整
1. 选中编辑区中的控件
2. 按住鼠标左键拖拽控件到新的位置

1. 左侧控件库和中间编辑区之间有一个分隔条

## 6. 文件操作

### 6.1 产品信息保存
1. 点击"文件"菜单中的"保存"选项
2. 选择保存路径和文件名
3. 产品信息将以JSON文件格式保存

### 6.2 产品信息加载
1. 点击"文件"菜单中的"打开"选项
2. 选择要加载的JSON文件
3. 产品信息将在编辑窗口中加载

### 6.3 UI布局保存
1. 在UI布局编辑器中点击"文件"菜单中的"保存"选项
2. 选择保存路径和文件名
3. UI布局将以.ui文件格式保存
4. **修复说明**：已修复QDesigner保存UI文件时的崩溃问题，确保保存功能稳定可靠

### 6.4 UI布局加载
1. 在UI布局编辑器中点击"文件"菜单中的"打开"选项
2. 选择要加载的.ui文件
3. UI布局将在编辑区中打开

- 支持完整的UI设计功能，包括控件拖拽、属性编辑、预览等

- **技术改进**：优化了writeOutForm方法中的contents方法调用逻辑，确保保存稳定性

### 6.6 UI交互逻辑编辑器
**功能概述**：
UI交互逻辑编辑器提供可视化编辑UI界面交互流程的功能，分为三个子功能模块：
1. **向导编辑**：编辑多个UI界面之间的跳转关系，创建UI向导流程
2. **逻辑时序编辑**：编辑业务逻辑运行流程，定义内部执行流程逻辑
3. **UI与执行模块绑定**：可视化绑定UI控件与执行模块，实现UI与后端逻辑的连接

**打开UI交互逻辑编辑器**：
1. 点击菜单栏中的"UI布局"→"打开UI交互逻辑"
2. 进入UI交互逻辑编辑界面

#### 6.6.1 向导编辑功能
向导编辑功能用于编辑多个UI界面之间的跳转关系，创建UI向导流程。

**模式切换**：
编辑器支持两种模式：
- **UI流模式**：编辑UI界面之间的跳转关系，创建向导流程
- **逻辑时序模式**：编辑业务逻辑运行流程

**UI文件管理**：
1. 在UI文件列表中查看所有产品UI文件
2. 设置主界面：点击"设为主界面"按钮，将某个UI设置为向导的起始页面
3. 查看UI文件详情：点击UI文件项，查看该文件的详细信息

**控件事件定义**：
1. 选择一个UI文件
2. 在控件事件定义区域选择控件
3. 选择事件类型（如clicked）
4. 输入事件名称
5. 选择目标UI页面（或选择"无跳转"）
6. 点击"添加事件定义"按钮

**运行向导**：
1. 确保已设置主界面
2. 点击"运行向导"按钮
3. 系统会根据控件事件定义构建向导页面顺序
4. 主界面作为第一个页面显示
5. 根据控件事件实现页面跳转（不是机械式的"下一步"、"上一步"）
6. 孤立UI（无跳转事件的UI）也会包含在向导中

**向导预览特点**：
- 显示实际的UI控件，而非占位符
- 基于控件事件实现页面跳转
- 自动绑定控件事件到目标UI页面
- 支持clicked等事件类型
- 实时预览向导运行效果

#### 6.6.2 逻辑时序编辑功能
逻辑时序编辑功能用于编辑业务逻辑运行流程，定义内部执行流程逻辑。

**功能说明**：
- 可视化编辑业务逻辑的执行顺序
- 支持条件分支和循环逻辑
- 定义数据流转和处理步骤
- 配置异步任务和并发执行

**操作步骤**：
1. 切换到"逻辑时序模式"
2. 在编辑区域添加逻辑节点
3. 连接节点定义执行流程
4. 配置节点参数和条件
5. 测试和验证逻辑流程

#### 6.6.3 UI与执行模块绑定功能
UI与执行模块绑定功能用于可视化绑定UI控件与执行模块，实现UI与后端逻辑的连接。

**功能说明**：
- 可视化绑定UI控件与执行模块
- 支持多种绑定类型（数据绑定、事件绑定、属性绑定）
- 实时预览绑定效果
- 管理绑定关系和依赖

**操作步骤**：
1. 选择要绑定的UI控件
2. 在绑定面板中选择执行模块
3. 配置绑定参数和映射关系
4. 测试绑定效果
5. 保存绑定配置

## 9. 智能打包功能

### 9.1 智能打包概述
智能打包功能可以将编辑好的产品信息和UI布局打包成可执行的软件包，包含完整的项目结构和构建脚本。

### 9.2 使用智能打包
1. 点击菜单栏中的"文件"→"智能打包"
2. 在弹出的对话框中填写打包配置信息：
   - 产品名称（支持中文，系统会自动转换为英文格式）
   - 版本号
   - 开发者信息
   - 产品描述
3. 点击"确定"开始打包

### 9.3 打包输出
打包完成后将在`packages`目录下生成：
- 完整的CMake项目结构
- 自动生成的main.cpp源代码
- 构建脚本（build.bat）
- 可执行文件
